# Исследования

- [01_eda.ipynb](notebooks/01_eda.ipynb): загрузка Raw Data, словарь колонок, очистка, сводные отчёты и выводы первичного EDA. Последняя ячейка сохраняет таблицу в `runtime/data/prepared/ctg_cleaned.csv`.
